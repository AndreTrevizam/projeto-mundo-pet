
# Mundo Pet - Sistema de Gerenciamento

Bem-vindo ao repositório do projeto **Mundo Pet**, um sistema de gerenciamento desenvolvido para facilitar a administração de um petshop, incluindo o controle de clientes, pets, serviços agendados e muito mais.

## 📋 Descrição do Projeto

O **PetShop** é uma aplicação desenvolvida para auxiliar na gestão de um estabelecimento de cuidados para animais de estimação. O sistema permite:

- **Cadastro de Clientes**: Armazenar informações dos donos dos pets.
- **Cadastro de Pets**: Registrar detalhes sobre os animais de estimação.
- **Agendamento de Serviços**: Marcar banho, tosa, consultas veterinárias, etc.


## Stack utilizada

- **Front-end:** HTML, CSS e JavaScript
- **Back-end:** JavaScript
- **Outras Ferramentas**: Git e Figma

## Rodando localmente

Clone o projeto

```bash
  git clone https://github.com/AndreTrevizam/projeto-mundo-pet.git
```

Instale as dependências

```bash
  npm install
```

Inicie o servidor

```bash
  npm run server
```

Inicie a aplicação

```bash
  npm run dev
```
